# Meal Prep AI - Planejador de Marmitas Inteligente

Este projeto é um organizador de marmitas semanal com lista de compras inteligente (que escala de acordo com a quantidade de pessoas) e integração com Inteligência Artificial para sugestão de receitas personalizadas com base nos ingredientes disponíveis em casa.

Este repositório foi construído utilizando uma stack moderna de **Full-Stack TypeScript** para demonstrar boas práticas de arquitetura, padrões de projeto e tecnologias de alta demanda no mercado.

---

## 🛠️ Tecnologias Utilizadas

### Backend
* **Linguagem:** TypeScript
* **Framework:** NestJS (Node.js) - Escolhido pela arquitetura sólida baseada em injeção de dependência e desacoplamento (similar ao Spring Boot).
* **ORM / Banco de Dados:** Prisma ORM com PostgreSQL.
* **Containers:** Docker para ambiente de desenvolvimento local.
* **IA:** Integração com Google Gemini API.

### Frontend / Mobile
* **Mobile:** React Native com Expo (compilação nativa para Android e iOS).
* **Web:** React com Vite e TailwindCSS (caso seja necessário painel administrativo ou versão web responsiva).
